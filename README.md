# 衣序 YIXU

个人衣柜和每日穿搭网页。为手机和电脑设计，全部衣柜数据保存在当前网址的浏览器 IndexedDB 中。

在线体验：https://ymuyi20-web.github.io/yixu-wardrobe/

代码仓库：https://github.com/ymuyi20-web/yixu-wardrobe

朋友打开体验网址即可使用，不需要登录。每人的衣柜保存在各自浏览器中，不会看到别人的照片。当前是本地规则推荐，自动识别、抠图和本人试穿尚未接入。

## 运行

使用 Node.js 22 或更新版本：

```powershell
npm install
npm run dev
```

本地地址：http://127.0.0.1:5186 。构建使用 `npm run build`，规则检查使用 `npm test`。

## 已完成

- 18 件可删除的示例衣物，自绘 SVG 插画和衣架浏览动画。
- 批量上传 JPG / PNG / WebP（每批 20 张，每张 20 MB 以内），本地压缩，人工确认分类、色标、风格、季节、适用气温和可穿/待洗状态。
- 衣柜搜索、分类、季节、喜欢和待洗筛选，编辑、删除及撤销。
- 根据季节、人工气温、场景、偏好和近期记录进行本地规则推荐，固定单品、同类替换。
- 搭配收藏、按日穿搭记录（同日覆盖）、个人照片和偏好。
- IndexedDB 持久化，完整 JSON 备份导出及校验恢复。
- 手机布局、键盘操作、原生模态对话框、减少动态效果支持。

## 清晰边界

本版不调用外部 AI。照片不会上传到第三方；分类、气温需手动输入，暂未接入自动识别、自动抠图、实时天气、本人试穿和跨设备同步。衣架为 SVG / 照片元素的 CSS 动效，不是生成的视频或真实 3D 衣物。

不是有账号、云端私有存储的在线衣柜；持久化仅限当前浏览器与当前网址。更换网址、设备或清除浏览器数据前需导出备份。备份包含照片，应私下保管。应用只允许 JPG / PNG / WebP data URL 图片进入备份恢复。

## 后续接入建议

1. 先用自己的 20–30 件衣服验证推荐。厚薄、材质、适温应保留人工修正。
2. 接入识别服务时使用服务器代理；API 密钥不得放在前端环境变量中。
3. 本人试穿按需生成，提交前明确照片接收方和费用预算，先用少量单品验证细节。
4. 多设备版本需账号鉴权、私有对象存储、授权访问和删除机制。
5. 当前根据用户选择部署到 GitHub Pages，发布源为 `codex/yixu-wardrobe` 分支的 `/docs` 目录。

## 更新在线版本

修改源文件后执行 `npm test` 和 `npm run build:pages`，将源码和 `docs/` 提交并推送。GitHub Pages 会发布 `/docs`。`dist/`、测试截图、备份、浏览器数据和凭据不会进入仓库。

## 视觉

冷调纸白 `#F4F5F2`、松绿 `#24473E`、衣柜灰绿 `#E8ECE1`、浅黄绿 `#E3EDBD` 与淡灰紫。展示文字采用 Noto Serif SC / 系统宋体，界面采用系统无衬线字体。签名交互为衣架侧向浏览和选中展开。外部 Google Fonts 只提供字体，不接收衣物或照片，离线时自动回退系统字体。
